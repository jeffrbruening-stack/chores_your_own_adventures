CHORES YOUR OWN ADVENTURE — V1 CORE EXPERIENCE CORRECTION PASS

The initial build is a good structural start, and the overall purple/gold visual direction and bottom navigation are generally good.

However, the current implementation has several major problems that need to be corrected BEFORE adding more advanced V1 features.

Current observed problems:

1. Character creation is completely missing.
2. New users are automatically assigned an emoji instead of creating a character.
3. The Home screen is essentially blank after login.
4. The Party screen is essentially blank.
5. The Shop contains no items.
6. The intro logo is visually wrong for the intended style.
7. The intro logo continuously bounces up and down.
8. Several screens appear to exist as routes/layouts but do not yet provide a functional game experience.

STOP adding advanced features for now.

Do not prioritize Cat Foley, AI planning, Boss Battles, Legendary Quests, notifications, or other later systems until the basic game loop described at the end of this prompt is working.

The immediate goal is:

CREATE CHARACTER → SEE QUEST → COMPLETE QUEST → EARN XP/GOLD → SHOP → BUY ITEM → EQUIP ITEM → SEE CHARACTER CHANGE

That loop must feel like an actual game.

⸻

1. CRITICAL — ADD THE MISSING CHARACTER CREATION FLOW

The current build skips character creation entirely.

This is incorrect.

Every USER has one global RPG character that follows them across all Parties.

A new user must intentionally create that character before entering the normal application.

Do not automatically assign an emoji avatar.

ADULT FIRST-TIME FLOW

For a brand-new adult:

Create Account
→ Create Party OR Join Party
→ CREATE YOUR ADVENTURER
→ Home

If the adult creates a Party, creating the Party must NOT automatically create a generic character for them.

KID FIRST-TIME FLOW

Kids are initially created by a Party Leader with:

* Display Name
* 4-digit PIN
* Party membership

The Party Leader does NOT design the kid’s character.

That is intentionally left to the kid because creating their own character is part of the fun.

Kid flow:

Enter Household Code
→ Select Kid/Adventurer
→ Enter PIN
→ if character has never been created: CREATE YOUR ADVENTURER
→ Home

On subsequent logins, character creation is skipped because the character already exists.

EXISTING TEST USERS

Existing accounts created by the current version may already have an automatically generated emoji/default avatar.

Do NOT treat that as completed character creation.

If an existing user does not have a valid completed character configuration, redirect them through Create Your Adventurer the next time they enter the app.

This first intentional creation does NOT trigger the seven-day character-change cooldown.

After initial character creation, base-character changes are subject to the previously specified seven-day cooldown.

* gender/body presentation;
* species;
* class;
* skin tone;
