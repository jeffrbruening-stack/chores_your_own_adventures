# CHORES YOUR OWN ADVENTURE — CHARACTER, PARTY, AND CORE FUNCTIONALITY CORRECTION PASS

The latest build has improved the structure, but testing has exposed several major problems.

Do NOT add new advanced features during this pass.

Fix the character system, equipment rendering, Party management, quest assignment, and the Party Goal crash first.

The current issues observed in actual testing are:

* Character sprites are far too small and crude.
* Species barely look different.
* Elf ears are visibly detached from the head.
* Dwarf and Gnome use essentially the same body proportions as Human/Elf.
* Class does not visually affect the starting character.
* Male/Female/Other presentation has no meaningful visual distinction.
* Eyes appear cross-eyed.
* Glasses make the face look even stranger.
* Stubble and mustache rendering are poor.
* Equipment can be equipped/unequipped but does not visibly change the character.
* There is no obvious interface to add kids/Party members.
* There is no obvious interface to assign quests to Party members.
* "Set a Goal for Your Party" crashes with a JavaScript error:
  `Cannot read properties of undefined (reading 'filter')`
* Character customization needs more fantasy color options.
* A Dumpster Fire background is required because obviously it is.

Fix these before moving forward.

---

# 1. CHANGE CHARACTER ART DIRECTION FROM STRICT 8-BIT TO 16-BIT PIXEL ART

The current character sprites are too small to support the customization system.

Do NOT abandon pixel art.

Instead, move the CHARACTER artwork specifically to a richer:

# 16-BIT / SNES-ERA CHIBI FANTASY RPG STYLE

The rest of the app may retain its existing retro UI style.

Characters should resemble classic 16-bit RPG sprites:

* clearly pixelated;
* compact/chibi proportions;
* larger heads for readability;
* distinguishable faces;
* readable hair;
* readable clothing;
* clearly visible equipment;
* clearly visible species differences.

Do NOT use smooth vector cartoons.

Do NOT use emojis.

Do NOT use photorealism.

Use larger logical sprite dimensions, approximately in the range of 64×96, 80×112, or 96×128 pixels per composed character as appropriate.

Display them substantially larger in the UI using nearest-neighbor/pixelated scaling.

The full character preview should occupy most of the Character Creation preview card.

The character should NOT be a tiny figure floating in a huge empty box.

Use CSS/image rendering appropriate for pixel art such as:

`image-rendering: pixelated`

where applicable.

---

# 2. MAKE SPECIES VISUALLY DISTINCT

Species cannot simply be Human plus one tiny alteration.

Create visibly distinct body/silhouette templates.

## HUMAN

Baseline proportions.

## ELF

* Slightly taller/slimmer than Human.
* Proper attached pointed ears integrated into the head sprite.
* Ears must not float beside the head.
* Slightly more angular fantasy appearance.

## DWARF

Dwarf MUST visibly be:

* shorter;
* stockier;
* broader torso;
* shorter legs.

Optional facial-hair options should look particularly appropriate on Dwarf characters.

Do NOT render Dwarf at Human height.

## GNOME

Gnome should visibly be:

* substantially shorter;
* smaller/narrower body than Dwarf;
* slightly larger head relative to body;
* clearly different silhouette from both Human and Dwarf.

## HALFLING

* shorter than Human;
* less stocky than Dwarf;
* proportionally distinct.

## ORC

Do more than turn a Human green.

Include recognizable original fantasy traits such as:

* broader build;
* slight tusks where readable;
* heavier jaw/brow;
* pointed or different ear shape.

Allow normal human skin colors AND fantasy skin colors.

## GOBLIN

Goblin should NOT just be a differently colored Orc.

Use:

* shorter stature;
* thinner limbs/body;
* larger pointed ears;
* more pronounced nose/head silhouette;
* clearly distinct body proportions.

All species remain cosmetic only.

# 3. IDENTITY / BODY PRESENTATION SHOULD ACTUALLY LOOK DIFFERENT

The current Masculine/Feminine/Any selections do not visibly change the character.

Create visible but simple stereotypical fantasy-game presentation differences.

This is visual customization only.

## MASCULINE

Possible baseline differences:

* slightly broader torso;
* pants/trousers default;
* masculine hair/facial-hair options.

## FEMININE

Possible baseline differences:

* slightly different body silhouette;
* option/default for skirt, dress, tunic/skirt, or other recognizable fantasy feminine clothing;
* feminine hair options.

Do not make this sexualized.

The point is simply that selecting Feminine should visually do something.

## ANY / OTHER

Use a neutral silhouette/default and allow all appearance options without restriction.

Do not mechanically restrict hair, colors, classes, or equipment based on identity selection.

# 8. FIX THE FACE

The current character frequently appears cross-eyed.

This needs to be corrected.

Use simpler, cleaner pixel faces.

Both eyes should:

* face the same direction;
* be symmetrically positioned unless deliberately creating an expression;
* not point inward toward each other.

Do not try to render detailed pupils if the sprite resolution cannot support them.

Two readable eye pixels/shapes are better than complex cross-eyed faces.

The default expression should be pleasant/neutral.

---

# 9. FIX GLASSES

Current glasses visually collide with the eyes and make the face look stranger.

Rebuild glasses as proper sprite overlays aligned to the character face.

Offer only a few GOOD styles initially.

For example:

* Round glasses
* Square glasses
* Small spectacles

They must:

* align with the eye line;
* remain attached to the face;
* not obscure the entire face;
* scale correctly for each species/head template.

If glasses cannot be made to look good on every species immediately, create species-specific alignment offsets.

Do not simply place the same SVG/icon coordinates over every character.

→ Traveler's Tunic visibly returns.

* Head
* Outfit
* Main Hand
* Off Hand
* Pet
* Pet Accessory
* Background
* Effect
